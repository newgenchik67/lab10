# Домашнее задание к работе 10

## Условие задачи (Вариант 30)

Составить программу, которая для заданной геометрической фигуры (фигура №30) предлагает меню выбора одной из операций:

1) рассчитать площадь;  
2) вывести определение фигуры;  
3) нарисовать фигуру;  
4) сравнить две фигуры по площади;  
5) выход.

Для заданной фигуры реализовать отдельные функции:

- `double area_figure(int k)` — вычисление площади фигуры на основе масштабного коэффициента $k$;  
- `void print_definition(void)` — вывод определения и геометрических свойств фигуры;  
- `void draw_figure(int k, char ch)` — отрисовка фигуры заданного масштаба указанным символом;  
- `double compare_figures(double s1, double s2)` — вычисление разности площадей двух фигур (${s}_{1}-{s}_{2}$).

## 1\. Алгоритм и блок-схема

### Алгоритм

1. Настроить русскую локализацию для корректного вывода сообщений.  
2. Организовать цикл `do-while`, чтобы программа работала до тех пор, пока пользователь не решит выйти.  
3. Показать меню с доступными действиями:  
   - `1` — рассчитать площадь фигуры;  
   - `2` — вывести определение фигуры;  
   - `3` — нарисовать фигуру;  
   - `4` — сравнить две фигуры по площади;  
   - `0` — завершить работу.  
4. Считать выбранный пункт `choice`.  
5. Выполнить действие в зависимости от выбора с помощью оператора switch: 
   - **Ветвь 1:** запросить у пользователя масштабный коэффициент `k`. Проверить условие корректности (`k > 0`). При корректных данных вызвать функцию `area_figure(k)` и вывести результат.  
   - **Ветвь 2:** вызвать функцию `print_definition()`, выводящую текст с определением и описанием структуры фигуры.  
   - **Ветвь 3:** запросить масштабный коэффициент `draw_k` и символ `ch`. Проверить условие корректности (`draw_k > 0`). При корректных данных вызвать функцию `draw_figure(draw_k, ch)`, выполняющую отрисовку по координатной сетке с помощью вложенных циклов.  
   - **Ветвь 4:** запросить масштабные коэффициенты для двух фигур (`k1` и `k2`). Рассчитать их площади с помощью `area_figure`, затем вызвать функцию `compare_figures(s1, s2)` и вывести сообщение о том, какая фигура больше и на какую величину (либо об их равенстве).  
   - **Ветвь 0:** вывести сообщение о завершении программы.  
   - **По умолчанию (default):** вывести сообщение о неверном пункте меню.  
6. Повторять цикл, пока пользователь не введёт пункт `0`.
